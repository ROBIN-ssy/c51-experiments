# 51 单片机实验合集（STC89C52 / Keil C51）

24 个实验工程，按外设一个个啃下来的完整记录。每个目录是一个独立的 Keil 工程，
`Objects/`、`Listings/` 等构建产物已剔除，只保留 `.c` / `.h` / `.uvproj` / `STARTUP.A51`。

## 这条线是怎么走的

```
点灯 → 数码管 → 按键 → 矩阵键盘 → 密码锁
                          ↓
        1602 字符屏 → 点阵屏 → 点阵动画
                          ↓
        串口收发 ←→ 定时器 ←→ DS1302 时钟 ←→ 可调时钟
                          ↓
        AT24C02 存储 → 红外遥控 → 蜂鸣器音乐
```

每个外设都是"先让它动起来，再让它可靠"：`LCD1602` 和 `25-LCD1602液晶显示实验`
是同一个器件的两个版本；`DS1302时钟` 到 `DS1302可调时钟` 是加了人机交互的版本。

---

## 怎么用

用 **Keil uVision（C51 版）** 打开任意目录下的 `.uvproj`，直接编译烧写。
芯片是 STC89C52RC（也可以用 `STC-ISP` 下载）。

> 注意：C51 版 Keil 和 MDK（ARM 版）不是同一个软件，别用错。

## 说明

- 工程文件是 `uvproj`（老版格式），新版 Keil 打开会自动升级
- `STARTUP.A51` 是启动代码，每个工程各带一份
- 代码风格是跟随教程逐步形成的，**早期实验和后期实验写法不一致**（比如延时函数的实现），
  这是如实保留的 —— 学习过程本来就是这样
